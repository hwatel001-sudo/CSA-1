# Java Practice Exercises

A collection of beginner-friendly Java programming exercises focused on practicing fundamental programming concepts, including loops, conditional statements, methods, strings, and basic algorithms.

## 📌 Project Overview

This project contains a series of Java exercises designed to strengthen problem-solving skills and understanding of core Java concepts.

Each exercise is implemented as a separate method in the `Main.java` file.

## 📚 Exercises

| Question | Method | Description |
|---|---|---|
| 1 | `charNumbers()` | Checks whether a character appears a specified number of times in a string. |
| 2 | `indexFinder()` | Counts how many times a given digit appears in a user-provided string. |
| 3 | `reverser()` | Reverses a string. |
| 4 | `condenser()` | Removes occurrences of a specified substring from a string. |
| 5 | `factors()` | Prints all factors of a given integer. |
| 6 | `divisibler()` | Prints numbers within a specified range that are divisible by a given integer. |
| 7 | `summer()` | Calculates the sum of all integers within a specified range. |
| 8 | `duplicator()` | Repeats a string a specified number of times. |
| 9 | `devoweler()` | Removes occurrences of a specified character from a string. |
| 10–11 | — | Not implemented. |
| 12 | `lengther()` | Determines whether the length of a user-provided string is even or odd. |

## 🛠️ Technologies Used

- **Language:** Java

## 🚀 Getting Started

### Prerequisites

Make sure the Java Development Kit (JDK) is installed.

Verify your installation:

```bash
java -version
javac -version
```

### Compile and Run

**1. Clone the repository**

```bash
git clone <repository-url>
```

**2. Navigate to the project directory**

```bash
cd <repository-folder>
```

**3. Compile the Java program**

```bash
javac Main.java
```

**4. Run the program**

```bash
java Main
```

The program executes the implemented exercises sequentially and prompts the user for input when necessary.
